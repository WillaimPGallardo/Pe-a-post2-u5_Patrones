Biblioteca API - POST 2 (Arquitectura con DTO)

Autor

William Peña



 Descripción del Proyecto

Este proyecto consiste en el desarrollo de una API REST utilizando **Spring Boot**, aplicando una arquitectura por capas junto con buenas prácticas como el uso de **DTO (Data Transfer Object)**, **Mapper**, **manejo global de errores** y **ResponseEntity**.

La aplicación permite gestionar una biblioteca mediante operaciones CRUD sobre la entidad **Libro**, garantizando una correcta separación entre la capa de presentación y la lógica de negocio.



Tecnologías Utilizadas

* Java 17
* Spring Boot
* Spring Web
* Spring Data JPA
* H2 Database
* Maven
* Lombok
* Jakarta Validation

Conclusión

Este laboratorio permitió aplicar conceptos avanzados en el desarrollo de APIs REST, como el uso de DTO para desacoplar la entidad, la implementación de mappers para transformación de datos y el manejo adecuado de errores.

Además, se reforzó la importancia de una arquitectura limpia y escalable.
